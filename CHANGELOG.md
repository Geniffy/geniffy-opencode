# Changelog

## 0.1.0

The first release.

- The Geniffy memory tools in OpenCode: the plugin adds Geniffy's MCP server to your config.
- Type `geniffy login` once, and each session starts with what Geniffy remembers about you and the project.
- Each turn is saved in the background when the session goes idle, who said what kept, with secrets and code
  blocks left out.
- `geniffy status`, `geniffy pause`, `geniffy resume` and `geniffy logout`, typed in the chat.
- Runs inside OpenCode: nothing else to install.
